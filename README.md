# Little Walk

Отдельный нативный SwiftUI-проект для iPhone, iOS 17+. Интерфейс на английском.

Little Walk помогает выбрать настроение и время для самостоятельной прогулки, замечать детали и сохранять воспоминания. Использует только Apple frameworks; сервер, ключи API и аккаунт пользователя не нужны.

## Запуск

Откройте `LittleWalk.xcodeproj`, выберите схему **LittleWalk** и iPhone Simulator, нажмите Run.

Для физического iPhone выберите свою команду в Signing & Capabilities. Bundle identifier: `com.hanwaygo.gos`.

```sh
xcodebuild -project LittleWalk.xcodeproj -scheme LittleWalk \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build

swiftc LittleWalk/WalkModel.swift Tests/WalkStoreChecks.swift -o /tmp/little-walk-store-checks
/tmp/little-walk-store-checks
```

## Реализованный сценарий

1. **Way Pulse.** Пять настроений — Clear, Fresh, Curious, Fast, Quiet. Выбор кнопкой, свайпом по дороге или VoiceOver adjustable action. Иллюстрация меняется вместе с настроением.
2. **Time Shape.** Длительность 15–120 минут, шаг 5 минут. Перетягивание линии, быстрые значения и VoiceOver. Опции спокойного начала, напоминания самостоятельно вернуться и остановки на отдых.
3. **Your Way.** От 3 до 6 глав в зависимости от длительности. 45 заготовленных подсказок для пяти настроений; Shuffle меняет сочетание и порядок средних глав и изгиб дороги. Опции влияют на текст плана. Иллюстрация явно обозначена как художественная, а не географическая.
4. **Flow Mode.** Таймер, пауза и продолжение, автоматическая смена подсказок по доле запланированного времени. Время восстанавливается после закрытия приложения; паузы исключены. После достижения выбранной длительности прогулку можно продолжить. Виброотклик только при взаимодействиях и смене главы в активном приложении.
5. **Leave a Mark.** Одно нажатие сразу сохраняет момент. Можно добавить текст, чувство и выбранную фотографию через системный PhotosPicker. Отдельные моменты можно редактировать и удалять. Название, координаты и доступ ко всей медиатеке не нужны.
6. **Way Memory.** Реальная длительность, дата, настроение, моменты, личная подпись и выбранное ощущение атмосферы. Три оформления: Postcard, Field note, Blue hour. PNG-карточка для системного Share Sheet; заметки моментов и фотографии не попадают в неё.
7. **Personal Landscape.** История реальных завершённых прогулок, фильтр по настроению, открытие и удаление воспоминаний. Художественная композиция из последних 12 прогулок; список содержит всю историю. При первом запуске история пустая.

**Маленькие интерактивные детали:** цветовой отклик дороги на касание; 12 переворачивающихся карточек наблюдений со свайпом и сохранением в моменты; спокойная солнечная анимация Just a pause. Последняя приостанавливает таймер и восстанавливает его предыдущий режим при закрытии. Поддерживается Reduce Motion.

## Изменения относительно первоначальной идеи

| Первоначальная функция | Реализованная замена |
| --- | --- |
| Автопостроение маршрутов по улицам и POI | Подбор локального плана прогулки по настроению |
| Круговой путь и географическая навигация | Напоминание выбрать собственный путь обратно |
| Избегание подъёмов и людных мест | Опция мягкого темпа и спокойные подсказки |
| Фон по GPS-окружению | Палитра по выбранному настроению |
| Голосовые заметки и геометки | Текст, чувство, время и выбранное фото |
| Погодные данные | Субъективная атмосфера, выбранная пользователем |
| Карта пройденных маршрутов | Художественный ландшафт сохранённых прогулок |

Приложение не измеряет расстояние, не получает GPS, не проверяет безопасность улиц и не выдаёт повороты. Фоновая геолокация, push, микрофон и камера не используются. Выбор фотографии не требует полного доступа к медиатеке. Фото в iCloud может потребовать загрузки на устройство; уже импортированные фото и все остальные данные доступны офлайн.

## Хранение и приватность

`Application Support/LittleWalk/walks.json` — атомарная запись активной прогулки и истории. Фото сохраняются отдельно, уменьшаются до 1600 px и перекодируются в JPEG. При удалении момента или прогулки удаляются соответствующие импортированные фото. При ошибке записи состояние откатывается к последней успешной записи; повреждённый исходный файл не затирается.

Нет аналитики, рекламы, платежей, облачного бэкенда, внешних SDK, регистрации или социальных функций. Системные резервные копии зависят от настроек устройства. Присутствует `PrivacyInfo.xcprivacy`.
